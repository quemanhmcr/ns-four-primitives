# Dense Depth-Two Protected Observability

**Claim level:** exact finite-packet definitions plus numerical no-output-cutoff audits. Uniform coercivity is an open theorem.

The most striking machine-flow observation is that severe first-curvature conditioning caused by protected shell separation is repaired at bracket depth two on dense reality-constrained packets.

## 1. Depth-two Gramian

For a protected state define

\[
B_1=\frac{T}{N}\frac{\mathcal A_\omega}{N}P,
\qquad
B_2=\frac{T}{N}\left(\frac{\mathcal A_\omega}{N}\right)^2P,
\]

and

\[
\boxed{G_2=B_1^*B_1+B_2^*B_2.}
\]

Every Fourier output generated by the full shell convolution is retained. No Galerkin output cutoff is allowed in this audit.

The normalized condition ratio is

\[
\eta_j
=\lambda_{\min,+}(G_j)/\lambda_{\max}(G_j).
\]

## 2. Large shell-separation audit

For dense random reality-constrained protected backgrounds on shells `(1,n^2)` with one fixed seed, the exact audit gives

| shell ratio `n` | `eta_1` | `eta_2` |
|---:|---:|---:|
| 10 | 1.5172e-2 | 1.1034e-1 |
| 20 | 3.6879e-3 | 1.1333e-1 |
| 40 | 9.0806e-4 | 1.1707e-1 |
| 80 | 2.2526e-4 | 1.1948e-1 |

Thus the first gap collapses by a factor about `67`, while the depth-two gap remains above `0.11` throughout the audited range.

At both depths the kernel has codimension one in the protected tangent space, and the null vector aligns with `omega` to numerical precision.

See `scripts/verify_dense_depth2_plateau.py`.

## 3. Why this is hypocoercive rather than elliptic

The first protected-curvature map becomes increasingly ill-conditioned as the two shell radii separate. The second bracket does not create a new dissipative operator; it transports the weak first-layer directions into outputs already measured by `T`.

This is exactly the structural pattern for which a Kalman/Hörmander or hypocoercive argument is designed:

\[
\text{first layer weak}
\quad\Longrightarrow\quad
\text{skew transport exposes it at the next layer}.
\]

The numerical plateau is therefore qualitatively stronger evidence than a positive first-order singular value at a few cutoffs.

## 4. Dense protected observability target

A plausible finite-packet theorem is the following.

**Dense Protected Observability Target.** Fix quantitative lower bounds excluding

- helicity-sector collapse;
- vanishing active participation / covariance density;
- exact safe geometric strata.

Then there should exist `c(delta)>0`, independent of the physical shell radii and of the full output cardinality, such that

\[
\boxed{
\langle v,G_2v\rangle
\ge
c(\delta)\,\mathcal M(u)\,
\operatorname{dist}(v,\operatorname{span}\{\omega\})^2,
}
\]

for protected tangent vectors `v`. Here `M(u)` is the physically correct state-dependent mobility/normalization; identifying it is part of the theorem.

The audit does not prove this statement.

## 5. The complementary branch cannot be discarded

Sparse coherent states can have much weaker `G_2` even when their support spans three dimensions. Therefore density cannot simply be assumed globally.

The intended proof architecture is a dichotomy:

- dense enough packet: use protected observability / hypocoercivity;
- sparse/coherent packet: use Spin-Shadow, cross-closure, phase-plane and Composition rigidity.

This is consistent with the clock-optimized H-flow split already developed in the repository.
