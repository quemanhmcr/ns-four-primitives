# Higher-Order Contact with the Protected Manifold

The second-order acceleration identity leaves one exceptional branch: `TF=0`, so the protected defect has zero opening acceleration. This note shows that the same structure iterates to all finite orders. The first nonzero opening jet is always generated by a time derivative of the nonlinear forcing, while viscosity drops out.

## 1. Setup

Fix a nondegenerate protected instant `t_0`:

\[
r(t_0)=0,
\qquad
\Delta(t_0)=EZ-H^2>0,
\]

with

\[
r=T(t)u,
\qquad
T(t)=\Lambda-a(t)-b(t)\operatorname{curl}.
\]

All derivatives below are evaluated at `t_0`.

From the protected acceleration theorem,

\[
a'=b'=0,
\qquad
r'=TF.
\]

## 2. Jet induction lemma

Let `m>=0`. Assume

\[
TF^{(j)}=0
\qquad
\text{for }j=0,1,\dots,m-1,
\]

where an empty condition is understood when `m=0`.

Then

\[
\boxed{
r^{(j)}=0
\quad\text{for }j=1,\dots,m,
}
\]

and

\[
\boxed{
a^{(j)}=b^{(j)}=0
\quad\text{for }j=1,\dots,m+1.
}
\]

Moreover

\[
\boxed{
r^{(m+1)}=TF^{(m)}.
}
\]

### Proof

Proceed by induction. Suppose all derivatives of `a,b` through order `n` and all derivatives of `r` through order `n` vanish.

Differentiating `r=T(t)u` `n+1` times, every mixed Leibniz term containing `T^{(j)}` with `1<=j<=n` vanishes. Thus

\[
r^{(n+1)}
=T u^{(n+1)}
-a^{(n+1)}u
-b^{(n+1)}\omega.
\]

The Navier-Stokes equation gives

\[
u^{(n+1)}
=F^{(n)}-\nu\Lambda^2u^{(n)}.
\]

By the induction hypothesis,

\[
T u^{(n)}=r^{(n)}=0.
\]

Since `T` commutes with `Lambda`,

\[
T\Lambda^2u^{(n)}=0.
\]

Therefore

\[
r^{(n+1)}
=TF^{(n)}
-a^{(n+1)}u
-b^{(n+1)}\omega.
\]

Differentiating the normal equations

\[
\langle r,u\rangle=0,
\qquad
\langle r,\omega\rangle=0
\]

`n+1` times, all terms containing lower derivatives of `r` vanish, giving

\[
\langle r^{(n+1)},u\rangle=0,
\qquad
\langle r^{(n+1)},\omega\rangle=0.
\]

But `T` is self-adjoint, `Tu=0`, and `T omega=0`, hence

\[
\langle TF^{(n)},u\rangle
=\langle F^{(n)},Tu\rangle=0,
\]

\[
\langle TF^{(n)},\omega\rangle
=\langle F^{(n)},T\omega\rangle=0.
\]

Since the Gram matrix of `u,omega` is invertible, the two normal equations force

\[
a^{(n+1)}=b^{(n+1)}=0.
\]

Therefore

\[
r^{(n+1)}=TF^{(n)}.
\]

This closes the induction.

## 3. First nonzero opening derivative

Suppose for some `n>=1`

\[
TF=TF'=\cdots=TF^{(n-2)}=0,
\]

but

\[
TF^{(n-1)}\ne0.
\]

Then

\[
r=r'=\cdots=r^{(n-1)}=0,
\qquad
r^{(n)}=TF^{(n-1)}.
\]

Since

\[
\mathcal Y=\langle r,r\rangle,
\]

all derivatives of `Y` below order `2n` vanish. Leibniz gives at order `2n`

\[
\mathcal Y^{(2n)}
=\binom{2n}{n}
\langle r^{(n)},r^{(n)}\rangle.
\]

Hence

\[
\boxed{
\mathcal Y^{(2n)}(t_0)
=\binom{2n}{n}
\|TF^{(n-1)}(t_0)\|_2^2
>0.
}
\]

For the critical defect `X=EY`, all lower derivatives of `Y` vanish, so

\[
\boxed{
\mathcal X^{(2n)}(t_0)
=E(t_0)\binom{2n}{n}
\|TF^{(n-1)}(t_0)\|_2^2.
}
\]

The first nonzero opening derivative is always **even and positive**.

## 4. Viscosity does not create the first opening jet

At every induction step, the viscous contribution is

\[
T\Lambda^2u^{(n)}
=\Lambda^2Tu^{(n)}
=0
\]

as long as all earlier protected jets vanish.

Thus the first nonzero departure from the protected manifold is generated entirely by the nonlinear forcing jet

\[
TF^{(n-1)}.
\]

Viscosity damps existing off-manifold defect, but it does not initiate departure from the exact protected manifold at any finite first-contact order.

## 5. Infinite-order contact

If

\[
TF^{(j)}(t_0)=0
\qquad\text{for every }j\ge0,
\]

then every time derivative of `r` and every time derivative of `Y` vanishes at `t_0`.

For a solution known independently to be real-analytic in time at `t_0`, this would imply

\[
r(t)=0
\]

on a time neighborhood of `t_0`, so the trajectory remains in the protected manifold there.

This note does **not** invoke time analyticity as a proved ingredient of the current program; the statement is recorded only as the natural endpoint of the finite-jet hierarchy. A future PDE closure must specify the function-space/analyticity theorem used if this implication is needed.

## 6. Rigidity interpretation

The reopening problem has become a descending hierarchy:

\[
\boxed{
\begin{aligned}
TF&\ne0
&&\Rightarrow\text{quadratic opening},\\
TF=0,\ TF'&\ne0
&&\Rightarrow\text{quartic opening},\\
TF=TF'=0,\ TF''&\ne0
&&\Rightarrow\text{sixth-order opening},\\
&\vdots
\end{aligned}
}
\]

High-order tangency is therefore not free. It requires successive nonlinear forcing jets to satisfy the same two-shell closure constraint.

The next structural problem is to prove a **finite-type closure theorem** for the periodic protected shell network: either a uniformly bounded jet order opens the defect quantitatively, or the state belongs to an invariant finite-dimensional special class. Such a uniform finite-type theorem is open.
