# Chiral Krylov Chain for the Passive FGR Bath

**Claim level:** exact operator representation plus numerical audits on protected Navier–Stokes packets. No topological classification theorem is claimed.

The FGR response in the viscously whitened bath is

\[
\mathcal R_\varepsilon(v)
=\langle g,(\varepsilon^2+H^2)^{-1}g\rangle,
\qquad
H=iD^{-1/2}AD^{-1/2}=H^*,
\qquad
g=Gv.
\]

This note compresses the entire bath response seen from `v` into one scalar Jacobi chain.

## 1. Exact antiunitary chiral symmetry

Work first in the complexification of the physical real Hilbert space. Let `J` be the canonical conjugation. The frozen Euler bath operator `A` and viscous metric `D` preserve the real subspace, hence

\[
JAJ=A,
\qquad
JDJ=D.
\]

Therefore

\[
\boxed{
JHJ=-H.
}
\]

For a coupling vector generated by a real physical perturbation,

\[
\boxed{Jg=g.}
\]

Thus the spectral measure of `H` seen from `g` is symmetric under `lambda -> -lambda`.

## 2. Lanczos chain has zero diagonal

Normalize

\[
q_0=g/\|g\|.
\]

Apply the Hermitian Lanczos recursion

\[
Hq_n
=b_{n+1}q_{n+1}+a_nq_n+b_nq_{n-1},
\qquad b_n\ge0.
\]

The antiunitary symmetry propagates alternately:

\[
Jq_n=(-1)^nq_n.
\]

Since `a_n=<q_n,Hq_n>` is real, applying `JHJ=-H` gives

\[
a_n=-a_n.
\]

Hence

\[
\boxed{a_n=0\quad\text{for every Lanczos level}.}
\]

The exact bath chain is therefore purely off diagonal:

\[
\boxed{
Hq_n=b_{n+1}q_{n+1}+b_nq_{n-1}.
}
\]

No scalar frequency detuning survives in this real protected FGR channel. All coherent bath structure is encoded in the positive hoppings

\[
b_1,b_2,b_3,\ldots.
\]

## 3. Exact continued fraction for FGR response

Let

\[
m(z):=\langle q_0,(H-z)^{-1}q_0\rangle.
\]

The Jacobi representation gives

\[
\boxed{
m(z)
=\cfrac{1}{-z-
\cfrac{b_1^2}{-z-
\cfrac{b_2^2}{-z-\ddots}}}.
}
\]

At `z=i epsilon`, chiral symmetry makes `m(i epsilon)` purely imaginary with positive imaginary part. Writing

\[
y_n
=\frac1{\varepsilon+b_{n+1}^2y_{n+1}},
\]

we obtain the positive continued fraction

\[
\boxed{
\mathcal R_\varepsilon(v)
=\frac{\|g\|^2}{\varepsilon}
\cfrac{1}{\varepsilon+
\cfrac{b_1^2}{\varepsilon+
\cfrac{b_2^2}{\varepsilon+\ddots}}}.
}
\]

Thus the full coherent Fourier bath, as seen from one protected direction, is represented exactly by one sequence of nonnegative scalars.

## 4. The first circulation moment is exactly the first hopping

Because `a_0=0`,

\[
\|Hq_0\|^2=b_1^2.
\]

Therefore the bath-circulation frequency of `52-fgr-circulation-composition-dichotomy.md` is

\[
\boxed{
\Omega_{\rm bath}^2(v)=b_1^2.
}
\]

The previous moment inequality becomes

\[
\boxed{
\mathcal R_\varepsilon(v)
\ge
\frac{\|g\|^2}{\varepsilon^2+b_1^2}.
}
\]

Hence the first coherent escape from passive damping is literally a large first Krylov hopping.

If that hopping is large, the response has been pushed into the next layer rather than cancelled by phase signs. The subsequent coefficients `b_2,b_3,...` record the repeated conservative recirculation that the Feshbach resolvent resums.

## 5. Relation to finite-depth protected brackets

## 6. Numerical reality-phase audit

For reality-compatible random protected phases on the shell pairs `(1,2)` and `(2,3)`, ten samples each were tested through the first ten Lanczos levels. The maximum observed diagonal coefficient satisfied

\[
\max_n|a_n|<1.5\times10^{-15}.
\]

This is an audit of the exact antiunitary theorem, not evidence for it.

Representative actual-state hopping data:

- full `(1,2)`: `b_1 ~= 0.307`, `b_2 ~= 0.304`;
- sparse noncollinear `(1,2)`: `b_1 ~= 0.930`, `b_2 ~= 0.500`;

- full `(2,3)`: `b_1 ~= 0.917`, `b_2 ~= 1.285`.

## 7. Why this is a representation change

The old coherent branch was a signed convolution network with many shared outputs and phase cancellations. The Feshbach-Krylov representation replaces it by

\[
\boxed{
\text{protected direction}
\to
\text{boundary coupling }\|g\|
\to
(b_1,b_2,b_3,\ldots)
\to
\text{positive boundary Green function}.
}
\]

All signed internal phase information enters only through the positive hopping coefficients after orthogonalization. The difficult question becomes a spectral/recursion question for a one-dimensional Jacobi chain.

This is closely related to the recursion/continued-fraction representation used in Mori-type memory formalisms, but no statistical closure is imposed here: the chain is constructed from the exact frozen deterministic bath operator.

## 8. Caution about topological language

A zero-diagonal Jacobi chain has the algebraic chiral symmetry familiar from bipartite tight-binding models. However a genuine topological invariant requires additional asymptotic hypotheses such as a gapped infinite-chain structure. None is established here.

The useful rigorous content at present is only:

1. exact zero diagonal;
2. positive hopping coefficients;
3. exact continued-fraction response;
4. exact termination when a Krylov hopping vanishes.

Whether the large-scale Navier–Stokes bath admits a useful asymptotic dimerization/topological classification is an open research question.
