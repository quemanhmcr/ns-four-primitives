# Nonlinear Base: Exact Fourier and Helical Algebra

We work first on the periodic domain with zero mean so that the Fourier algebra is discrete and `Lambda^{-1}` has no zero-mode ambiguity. Extension to other settings is a separate analytic step.

## 1. Rotational form

For divergence-free `u`,

\[
(u\cdot\nabla)u=\nabla(|u|^2/2)-u\times\omega,
\qquad
\omega=\nabla\times u.
\]

After Leray projection,

\[
\partial_tu=F-\nu\Lambda^2u,
\qquad
F=P(u\times\omega).
\]

Because `u` and `omega` are divergence-free,

\[
\langle u,F\rangle=0,
\qquad
\langle\omega,F\rangle=0.
\]

## 2. Helical basis

For each nonzero wavevector `k`, choose orthonormal real vectors `e_1(k),e_2(k)` perpendicular to `k` with

\[
e_2(k)=\widehat k\times e_1(k).
\]

Define

\[
h_s(k)=\frac{e_1(k)+is e_2(k)}{\sqrt2},
\qquad s\in\{+1,-1\}.
\]

Then

\[
ik\times h_s(k)=s|k|h_s(k).
\]

Write

\[
\widehat u(k)=\sum_s z_s(k)h_s(k),
\qquad
\widehat\omega(k)=\sum_s s|k|z_s(k)h_s(k).
\]

## 3. Exact pair coefficient

Fix `a+b=r`. The contribution of the ordered pair and its swap to the Lamb vector is

\[
\widehat u(a)\times\widehat\omega(b)
+
\widehat u(b)\times\widehat\omega(a).
\]

For input helicities `s_a,s_b`, the vector factor is

\[
(s_b|b|-s_a|a|)
\,h_{s_a}(a)\times h_{s_b}(b).
\]

Projection onto output helicity `t` gives

\[
\boxed{
C_{r;a,b}^{t,s_a,s_b}
=
(s_b|b|-s_a|a|)
\overline{h_t(r)}\cdot
\big(h_{s_a}(a)\times h_{s_b}(b)\big).
}
\]

This formula is gauge-dependent in complex phase but its magnitude is gauge invariant.

## 4. Same-spin parents

Let `s_a=s_b=s` and define

\[
\alpha=|a|,\quad
\beta=|b|,\quad
\rho=|a+b|,
\]

\[
S=\alpha+\beta,
\qquad
\Delta=|\alpha-\beta|,
\qquad
A=|a\times b|.
\]

A direct helical calculation yields

\[
\boxed{
|C^{t,s,s}|
=
\frac{1}{2\sqrt2}
\Delta\frac{A}{\rho\alpha\beta}
(S+ts\rho).
}
\]

Three exact selection mechanisms are visible:

1. **Radial degeneracy:** `Delta=0` kills the interaction.
2. **Angular degeneracy:** `A=0` kills collinear pairs.
3. **Helicity selection:** the two output helicities carry the complementary factors `S+rho` and `S-rho`.

No generic Holder or Sobolev estimate retains all three factors simultaneously.

## 5. Why this is the correct starting point

Every proposed cascade obstruction should be tested against this coefficient before being elevated to a global estimate.

In particular:

- a claimed angular gain must survive the exact `A` factor;
- a claimed helicity gain must use the correct `S +/- rho` branch;
- any sparse-network model must include all convolution outputs generated by the same parent pair, not only the output selected by the model.
