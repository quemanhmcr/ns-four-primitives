# Active-Frame Planar Rigidity

The preceding notes provide two independent local controls on the projective angle between handoff planes:

1. consecutive handoffs are controlled by the Plane-Turning Bridge coefficient;
2. equal-heat cancellation pairs at one output are controlled by the Resonant Diamond Cross-Closure coefficient.

This note packages those local statements into an exact finite-network rigidity theorem.

## 1. The handoff-plane graph

Consider a finite family of nondegenerate same-spin handoffs. Associate to every handoff `e` its unoriented parent plane

\[
\Pi_e\in\mathbb{RP}^2.
\]

Construct a graph `G` whose vertices are the handoffs and whose edges are of two types.

### Sequential edge

Two handoffs are sequential if they occur in a triple of radially ordered same-spin backbone modes

\[
K,Q,R,
\qquad
|K|<|Q|<|R|,
\]

with planes

\[
\Pi_e=\operatorname{span}\{K,Q\},
\qquad
\Pi_f=\operatorname{span}\{Q,R\}.
\]

Let `delta_ef` be their projective angle. Define the normalized bridge obstruction

\[
\boxed{
\varepsilon_{ef}^{\rm br}
:=
\frac{\sqrt2\,|C_{\rm bridge}|}
{(|R|-|K|)\sin\theta_{KQ}\sin\theta_{QR}}.
}
\]

The Plane-Turning Bridge Lemma gives

\[
\boxed{
|\sin\delta_{ef}|\le\varepsilon_{ef}^{\rm br}.
}
\]

### Resonant-cancellation edge

Two handoffs are resonantly coupled if they are same-spin equal-heat decompositions of one output

\[
r=a_++a_-=c_++c_-,
\]

in the midpoint notation

\[
a_\pm=\frac r2\pm x,
\qquad
c_\pm=\frac r2\pm y,
\qquad
|x|=|y|=R.
\]

Let `phi_ef` be the projective azimuthal angle between the two pair planes around `r`. When the radial and angular Selection factors are nonzero, define

\[
D_{ef}
:=
\frac{\rho R^3}
{2\sqrt2(\rho/2+R)^3}
\left(|\cos\theta_x|+|\cos\theta_y|\right)
|\sin\theta_x\sin\theta_y|,
\]

and the normalized cross-closure obstruction

\[
\boxed{
\varepsilon_{ef}^{\rm cross}
:=\frac{|C_\times|}{D_{ef}}.
}
\]

The Resonant Diamond Cross-Closure Lemma gives

\[
\boxed{
|\sin\phi_{ef}|\le\varepsilon_{ef}^{\rm cross}.
}
\]

Thus both edge types control exactly the same geometric object: projective plane separation.

## 2. Projective path inequality

Let

\[
d_{\mathbb{RP}^2}(\Pi,\Pi')\in[0,\pi/2]
\]

denote the angle between unoriented planes. For any path

\[
e_0,e_1,\dots,e_m
\]

in `G`, the triangle inequality gives

\[
\boxed{
d_{\mathbb{RP}^2}(\Pi_{e_0},\Pi_{e_m})
\le
\sum_{j=0}^{m-1}
 d_{\mathbb{RP}^2}(\Pi_{e_j},\Pi_{e_{j+1}}).
}
\]

For an edge with normalized obstruction `epsilon<1`, either local lemma yields

\[
d_{\mathbb{RP}^2}(\Pi_e,\Pi_f)
\le\arcsin\varepsilon.
\]

Hence

\[
\boxed{
d_{\mathbb{RP}^2}(\Pi_{e_0},\Pi_{e_m})
\le
\sum_{j=0}^{m-1}\arcsin\varepsilon_{e_je_{j+1}}.
}
\]

This is the finite-frame **Plane Propagation Inequality**.

## 3. Zero-defect planar rigidity

Assume `G` is connected, all Selection denominators above are nonzero, and every sequential/cross-closure obstruction vanishes:

\[
\varepsilon_{ef}=0
\qquad\text{for every edge of }G.
\]

Then every adjacent pair of planes agrees exactly. Connectivity therefore gives a single plane `Pi_*` such that

\[
\boxed{
\Pi_e=\Pi_*
\qquad\text{for every handoff }e.
}
\]

This is the **Zero-Defect Active-Frame Rigidity Theorem**.

If the active Fourier support of a closed finite frame is generated by the parent modes and convolution outputs represented by this connected graph, then every such mode lies in `Pi_*`, because sums and differences of vectors in a plane remain in that plane. The resulting closed active frame is therefore two-dimensional in Fourier geometry.

This last sentence is a statement about the closed active frame. It does **not** assert that arbitrary modes of a full Navier-Stokes solution outside the selected frame vanish.

## 4. Quantitative finite-frame rigidity

Suppose every edge of a connected graph satisfies

\[
\varepsilon_{ef}\le\varepsilon<1.
\]

Choose a root handoff `e_*`. If the graph diameter is at most `D`, then every handoff satisfies

\[
\boxed{
d_{\mathbb{RP}^2}(\Pi_e,\Pi_{e_*})
\le
D\arcsin\varepsilon.
}
\]

Thus a finite active frame with bounded graph diameter and small normalized composition obstructions is quantitatively close to one global plane.

The dependence on `D` is explicit and cannot simply be discarded. A long path can rotate slowly while every local edge defect is small. Controlling this diameter/slow-turning loophole is part of the infinite-cascade problem.

## 5. Relation to the planar endpoint

If the *full* Fourier support locks to one fixed plane, `09-planar-endpoint.md` reduces the system to the globally regular 2D3C equations. Therefore the zero-defect endpoint selected by the convolution algebra is not dangerous.

The proof architecture can now be stated more sharply:

\[
\boxed{
\text{nondegenerate nonplanar active frame}
\Longrightarrow
\text{nonzero bridge/cross-closure obstruction}.
}
\]

The unresolved problem is no longer classification of exact zero-defect frames. It is a **quantitative compactness problem**: show that a hypothetical singular cascade cannot escape by using active frames whose graph diameter grows while each local normalized obstruction tends to zero.

## 6. Next target: critical active-frame compactness

A useful closing statement would be a theorem of the following form.

**Critical Active-Frame Compactness Lemma (open).** From any sequence of scale-normalized positive critical escape events with bounded normalized critical mass and vanishing leakage/control action, extract a connected active subframe of uniformly bounded effective diameter carrying a fixed fraction of the positive flux.

Combined with the quantitative rigidity above, such a lemma would force a subsequential planar critical profile. One would then need to connect that profile rigidity to a standard Navier-Stokes continuation/blow-up compactness argument.

This compactness statement is not proved here. The exact zero-defect classification and the finite-diameter quantitative estimate are proved.
