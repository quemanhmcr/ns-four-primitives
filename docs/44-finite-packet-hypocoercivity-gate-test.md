# Finite-Packet Hypocoercivity Gate Test

**Claim level:** exact operator setup plus numerical finite-packet stress tests.  The rank/gap pattern below is evidence for a theorem target, not a proof of a cutoff-uniform PDE estimate.

This note tests the physical-shift proposal from `42-protected-connection-curvature.md` in the most direct finite setting available: an exact protected two-shell state, the actual frozen Euler connection, and no Fourier output cutoff.

## 1. Exact frozen protected connection

At a nondegenerate protected state let

\[
T=\Lambda-a-b\,\mathrm{curl},
\qquad
P=\mathbf 1_{\ker T},
\]

so that `P` consists of the `+` shell `|k|=alpha` and the `-` shell `|k|=beta`.  Freeze

\[
\mathcal A_{\omega_0}v=P_{\rm Leray}(v\times\omega_0).
\]

The first protected curvature map on the protected tangent space is

\[
\boxed{B_1:=T\mathcal A_{\omega_0}P.}
\]

No Fourier output cutoff is imposed: every nonzero output generated by the finite shell convolution is retained.

There is one exact unavoidable null direction,

\[
\boxed{B_1\omega_0=0,}
\]

because `A_{omega0} omega0=P(omega0 x omega0)=0`.

The central question is whether further null directions or asymptotically small singular values survive away from already classified safe strata.

## 2. Depth-one full-convolution audit

For random, random-phase, equal-amplitude, planar-support and sparse protected backgrounds, the exact map `B_1` was built in the full complex helical basis.  On comparable shell pairs from `(1,2)` through `(49,50)`, every tested non-collinear background had

\[
\boxed{\ker B_1=\operatorname{span}\{\omega_0\}.}
\]

Representative squared condition ratios

\[
\eta_1:=\sigma_{\min,+}(B_1)^2/\sigma_{\max}(B_1)^2
\]

were typically `0.15--0.35` for full/equal/random-phase states and remained order one as shell cardinality increased.

A previous ball-cutoff experiment produced extra nullspaces and apparent high-shell gap loss.  Removing the output cutoff eliminated those artifacts.  Full convolution closure is therefore essential even for this linearized curvature test.

## 3. Phase-only tuning does not create a near-null branch

At fixed equal modal magnitudes, randomize only the Fourier phases.  Hundreds of samples gave

- shells `(1,2)`: `eta_1 >= 0.288` in 240 samples;
- shells `(4,5)`: `eta_1 >= 0.215` in 160 samples;
- shells `(5,6)`: `eta_1 >= 0.306` in 100 samples.

Thus no phase-only near-null mechanism was found on these full packets.  By contrast, random-amplitude samples with lower participation ratio produced smaller gaps.  Weak curvature is therefore empirically associated more strongly with amplitude concentration/sparsity than with unconstrained phase tuning.

This does **not** exclude specially optimized coherent phase configurations; it says that the naive phase-cancellation loophole is not visible in the first-curvature singular spectrum at fixed full support.

## 4. Shell nonlocality weakens depth one

For nested shells `(1,n^2)`, depth-one conditioning deteriorates as `n` grows.  Representative random-state minima were

\[
\eta_1\approx
0.17,0.12,0.068,0.050,0.039,0.019,0.015
\]

for ratios `n=2,3,4,5,6,8,10`.

This is a real geometric loss, not merely the scalar slope degeneration of the optimal multiplier: dividing out the sector slopes did not restore a uniform gap.

Hence a depth-one theorem cannot be uniform over arbitrarily nonlocal protected shell ratios.

## 5. Depth-two bracket recovery

Normalize the frozen connection by the top protected frequency `N=max(alpha,beta)` and form the exact no-cutoff finite-depth Gramian

\[
\boxed{
G_m
=\sum_{j=1}^m
\left[(T/N)(\mathcal A_{\omega_0}/N)^jP\right]^*
\left[(T/N)(\mathcal A_{\omega_0}/N)^jP\right].
}
\]

For the nonlocal family `(1,n^2)`, the depth-two gap

\[
\eta_2=\lambda_{\min,+}(G_2)/\lambda_{\max}(G_2)
\]

recovered substantially:

| shell ratio | `eta_1` | `eta_2` |
|---:|---:|---:|
| 2 | `1.76e-1` | `1.35e-1` |
| 4 | `6.79e-2` | `8.52e-2` |
| 6 | `3.91e-2` | `8.73e-2` |
| 8 | `1.89e-2` | `5.37e-2` |
| 10 | `1.52e-2` | `1.10e-1` |

The nullspace remained exactly the `omega_0` direction for these generic states.  Thus weak first-curvature directions are genuinely opened by a second frozen connection bracket in the audited range.

This is the finite-packet signature expected from hypocoercivity rather than ellipticity.

## 6. Exact safe-stratum compatibility

For rationally nested shells, choose one `+` mode and one `-` mode on the same Fourier line.  These are the protected zero-nonlinearity heat-line states already classified by the reset trichotomy.

On these states the frozen Gramian has four null directions in the tested complex representation, and depth two does **not** remove them.  Systematic enumeration on `(1,4)`, `(1,9)`, and `(4,16)` gave

\[
\boxed{
\text{extra depth-one kernel}
\iff
\text{the two active cross-spin wavevectors are collinear}
}
\]

for every single-pair choice tested.

Thus the bracket test does not falsely coercivize the exact heat endpoint.

## 7. Quadratic opening away from the heat line

Perturb a collinear heat-line background by an off-line modal amplitude `epsilon`.  For shells `(1,n^2)`, `n=2,3,4`, the depth-two gap obeyed over `epsilon=10^{-4}--3\times10^{-2}`

\[
\boxed{\eta_2(\epsilon)\asymp c_n\epsilon^2,}
\]

with fitted log-log slopes

\[
1.999750,\quad1.999744,\quad1.999748
\]

and `c_n` between approximately `0.28` and `0.33`.

At `epsilon=0` the extra kernel is exact; at every tested `epsilon>0` the rank instantly returns to maximal rank modulo `omega_0`.

This suggests the correct coercivity is **defect weighted** rather than uniform:

\[
\text{hypocoercive gap}
\sim
\operatorname{dist}(u,\mathcal M_{\rm heat-line})^2
\]

near the safe stratum.

## 8. The theorem target exposed by the test

The numerical evidence points to a finite-packet statement of the form

\[
\boxed{
\langle v,G_2(u)v\rangle
\ge
c\,\mathfrak g(u)
\operatorname{dist}(v,\operatorname{span}\{\omega\}\oplus\mathcal N_{\rm safe}(u))^2,
}
\]

where

- `g(u)` is a scale-normalized geometric defect that vanishes exactly on the classified safe/degenerate strata;
- `N_safe(u)` is nontrivial only on those strata;
- `c` should be independent of the physical frequency scale on normalized packets.

The data indicate that depth two may be sufficient on generic protected packets.  No theorem of uniformity in shell ratio, shell cardinality, or all amplitudes is claimed.

## 9. Why this matters for the physical shift

The source identity

\[
\Gamma_{\rm esc}=\langle r,\mathfrak K u\rangle
\]

changed the gap from a signed cubic estimate into curvature work.  This finite-packet audit supplies the missing dynamical evidence:

- first curvature is already almost everywhere coercive modulo the exact helicity null direction;
- second curvature repairs weak nonlocal directions in the tested range;
- the remaining exact degeneracy is the already regular heat-line stratum;
- proximity to that stratum opens with a clean quadratic law.

That is qualitatively different from another Sobolev estimate.  It is the pattern of a genuine skew-dissipative/hypocoercive geometry.
